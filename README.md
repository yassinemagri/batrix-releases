# BATRIX

### Monitor Your Battery. Understand Its Health.

BATRIX is a Windows desktop application designed to provide a clear overview of your laptop's battery condition and performance.

It helps users understand their battery health, monitor power status, and estimate remaining battery runtime through a clean and intuitive interface.

## Features

- **Battery Monitoring** — View battery percentage and current status.
- **Battery Health** — Check estimated battery health and wear level.
- **Power Status** — Monitor charging and discharging activity.
- **Runtime Estimation** — View estimated remaining battery runtime.
- **Multilingual Interface** — Available in English, French, and Arabic.
- **Update Checker** — Check for new application releases.

## Interface

BATRIX features a modern and minimal interface designed to make battery information easy to understand.
